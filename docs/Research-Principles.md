# Research principles

1. **Speed of learning** beats feature completeness.
2. **Reproducibility** — every result has a config hash and registry ID.
3. **Replaceability** — engines are adapters; interfaces stay stable.
4. **Write it down** — failures and abandoned methods go in `research/failures/`.
5. **Lab is sacred** — explore in `lab/` without polluting core.
6. **Benchmarks are first-class** — do not bury comparative work inside ad-hoc scripts.
7. **No product theater** — if it does not improve models faster, drop it.

This is an **AI Research Platform**. OCR is the first track, not the identity.
