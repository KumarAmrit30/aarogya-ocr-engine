# Lab

Exploration sandbox. Crazy ideas live here — not production, not training pipelines.

| Folder | Purpose |
|--------|---------|
| `experiments/` | One-off lab experiments |
| `prototypes/` | Short-lived prototypes |
| `playground/` | Interactive scratch (gitignored contents) |
| `scratch/` | Throwaway (gitignored contents) |
| `archived/` | Retired lab work worth keeping |

**Hard rule:** `core/`, `engines/` production paths, and CI must never import `lab/`.

See `docs/Lab-Guidelines.md`.
