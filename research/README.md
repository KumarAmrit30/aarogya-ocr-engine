# Research Memory

Institutional memory for the Aarogya AI Research Platform.

Six months from now you will ask: *Why did we stop using PARSeq?*
Write it down here so we do not repeat dead ends.

| Folder | Purpose |
|--------|---------|
| `notes/` | Working notes |
| `hypotheses/` | Stated hypotheses before experiments |
| `findings/` | Confirmed findings |
| `failures/` | Postmortems and abandoned approaches |
| `papers/` | Paper summaries / bib notes |
| `meeting-notes/` | Lab discussions |

Templates live in each subdirectory.
